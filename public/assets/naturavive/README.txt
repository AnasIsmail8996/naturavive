NaturaVive Full Landing Page — Next.js Asset Pack

Copy `public/assets/naturavive/` into your Next.js project.

IMPORTANT: product names, prices, ratings, Add to Cart buttons, benefit card text, testimonials, headings and CTA text should be HTML/CSS — not baked into primary reusable images.

Folders:
brand/ logos + favicon + SVG
hero/ 10 text-free hero backgrounds + transparent 4-product cluster
mobile/ mobile hero backgrounds
backgrounds/ text-free section backgrounds
products/ 4 standalone transparent product visuals PNG/WebP
icons/ editable SVG UI/benefit/social icons
trust/ standalone trust icons
ingredients/ ingredient photo + ingredient crops
testimonials/ separate transparent avatars
subscribe/ lifestyle photo
decorations/ transparent leaf overlays, glow, divider
sections/ composition references only
reference/ original landing page references

Suggested usage: use `next/image`; use hero backgrounds with Swiper, and animate product PNGs/cluster via Motion/Framer Motion.
